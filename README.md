# Data Structures and Algorithms: Lab Codes

A collection of C++ programs written for the Data Structures and Algorithms course lab sessions (Semester 3, Cyber Security). Each lab folder contains the solutions to that lab's tasks, with comments explaining the logic.

## Repository Structure

| Folder | Topic | Programs |
|---|---|---|
| Lab 1 (Arrays, Pointers & Structures) | Arrays, pointers, structures | Student Performance, Bank Account, Employee Salary |
| Lab 2 (Pointers & Linked Nodes) | Pointer arithmetic, linked nodes | Maximum of Three Numbers, Reverse Array, Linked Nodes |
| Lab 3 (Dynamic Memory Allocation) | `new` and `delete` | Dynamic Products, Dynamic Character, Dynamic 2D Matrix |
| Lab 4 (Array Operations) | Insertion, deletion, searching | Insert (start, middle, end), Delete (start, middle, end), Linear Search, Binary Search |
| Lab 5 (Singly Linked List - Insertion) | Singly linked list insertion | Insert at Beginning, End, Middle, Before a Value, Menu-Driven Program |
| Lab 6 (Singly Linked List - Deletion) | Singly linked list deletion | Delete at Start, End, Middle, by Value |
| Lab 7 (Doubly Linked List) | Doubly linked list | Student Roll Numbers, Product IDs |
| Lab 8 (Sorting & Searching) | Sorting and searching algorithms | Selection, Bubble and Insertion Sort with Binary Search (menu-driven) |
| Lab 9 (Stack) | Array-based stack | Push, Pop, Search |
| Lab 10 (Stack using Linked List) | Linked list stack | Browser Back Button, Text Editor Undo, Decimal to Binary |
| Lab 11 (Queue) | Queues | Bank Token System, Linked List Queue, Circular Queue, Reverse a Queue |

## Concepts Covered

- Arrays and structures
- Pointers and pointer arithmetic
- Dynamic memory allocation
- Singly and doubly linked lists
- Sorting algorithms (selection, bubble, insertion)
- Searching algorithms (linear, binary)
- Stack (array and linked list implementations)
- Queue (array, linked list and circular implementations)

## Tools Used

- **Language:** C++
- **IDE:** Dev-C++ 5.11
- **Compiler:** TDM-GCC 4.9.2
